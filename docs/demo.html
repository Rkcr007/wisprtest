Trust contract

Speed is conditional. Safety is not.

Every action carries a class. Only reversible actions may execute from a partial transcript.

RFocus, hover, scroll, expand, read-only navigationMay speculate · rollback retained
CSubmit, delete, approve, any state mutationNever speculate · final + explicit yes
ALow confidence or structurally drifted screenPre-stage reticle · explicit yes
STest-data creationPreview first · explicit approval

Drift forces Class A before confidence is considered. A confident alias cannot prove that remembered structure is still current.
